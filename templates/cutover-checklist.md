# Cutover checklist

Job list and dates: ____________________  Cutover date (T): ____________  Data owner: ____________________

Print this, tick it, sign it, file it with the reconciliation sign-off. The reasoning behind each line is in the
[cutover runbook](../09-cutover-runbook.md).

## Before T

- [ ] Scope decisions agreed in writing
- [ ] Cutover date agreed with controller, payroll provider and accountant
- [ ] Contracts checked for software, format and document storage requirements
- [ ] Jobs in or near dispute identified with counsel
- [ ] Cost code list frozen; crosswalk complete
- [ ] Field mappings written and reviewed
- [ ] Job cost tied to the GL in the old system
- [ ] Trial load 1 reconciled and signed
- [ ] Trial load 2 reconciled and signed
- [ ] Training done in the test system
- [ ] Subcontractors and owners briefed on anything they will see change
- [ ] Old system read-only access or archive plan agreed

## After T

- [ ] Parallel run for one period; differences explained and signed off

- [ ] Double entry stopped

- [ ] Mappings, crosswalk, sign-offs and issue log handed to the new system's owner
